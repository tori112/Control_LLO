## О проекте

Врачи вручную отслеживали даты выписок льготных лекарств в Excel, что приводило к пропускам сроков и потере рейтинговых баллов (влияет на зарплату). Я разработала систему, которая автоматически рассчитывает дату следующей выписки (последняя выписка + 90 дней), показывает статус (просрочено / скоро / в норме) и позволяет врачам видеть только своих пациентов.

### Функционал

- Автоматический расчёт статусов по серверному времени
- Ролевая модель: врачи видят только пациентов своего участка
- Режим «Все врачи» с фильтром по отделениям
- Фильтрация по льготам (777, 775, 778), статусу, поиск по ФИО
- Пагинация, тёмная тема
- Импорт из Excel (автоопределение колонок)
- Экспорт отчётов в Excel
- Список назначенных лекарств в карточке пациента
- Кнопка «Сегодня» для быстрой установки даты выписки
- Логирование действий пользователей
- Резервное копирование и восстановление через JSON
- Админ-панель с паролем (защита от случайного доступа)

### Технологии

- **Frontend:** HTML, CSS, JavaScript (Vanilla)
- **Backend:** PHP (REST API)
- **Хранилище:** JSON (без базы данных)
- **Импорт/экспорт:** Excel (XLSX) через SheetJS
- **Сервер:** Astra Linux, Apache, PHP 8.2
- **Инструменты:** PowerShell (SSH, SCP)

### Как это работает

1. Врач открывает программу в браузере
2. Выбирает себя из списка → видит только своих пациентов
3. Смотрит статусы (красный — срочно, оранжевый — скоро, зелёный — в норме)
4. При выписке нажимает ✏️, ставит дату, нажимает «Сохранить»
5. Следующая дата выписки пересчитывается автоматически (последняя + 90 дней)

## Почему этот проект полезен

- Снижает время врача на контроль выписок с 15–20 минут до 1–2 минут
- Предотвращает пропуски сроков (влияет на рейтинговую оплату труда)
- Исключает ручной подсчёт дат
- Даёт заведующему прозрачный контроль через логи и отчёты
